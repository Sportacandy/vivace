# 选项

**选项** 菜单包含首选项和界面配置。

- **首选项…**（`Ctrl+P`）— 主设置对话框：常规、界面、字幕、键盘和鼠标、播放列表、
  驱动器、电视、文件类型、更新、网络和高级。更改会立即应用；**取消** 会还原它们。
  - **网络** 包含 OpenSubtitles、YouTube、代理和投射四个选项卡；**代理** 用于
    配置可选的 HTTP 或 SOCKS5 代理，应用于整个程序（OpenSubtitles 搜索、更新
    检查，以及仅在 HTTP 时的媒体播放和 yt-dlp）；**投射** 用于固定
    *播放 ▸ 投射到 ▸ 智能手机/平板电脑* 所监听的端口。OpenSubtitles 账户密码
    和代理密码现在都安全存储在您操作系统的凭据管理器中，而不是存储在
    Vivace 自身的设置里。
- **在系统托盘中显示图标** — 让 Vivace 可从托盘访问。
- **工具栏**
  - **工具栏** / **控制栏** — 显示或隐藏每个栏。
  - **编辑主工具栏…** / **编辑控制栏…** — 选择显示哪些按钮及其顺序和图标大小。
- **状态栏**
  - **显示状态栏** 及其显示内容：**视频信息**、**音频信息**、**格式信息**、
    **比特率信息**、**帧计数器**、**显示总时长**、**显示剩余时间** 和
    **显示带毫秒的当前时间**。

**提示：** 整体布局（Basic / Mini / MPC）在 *首选项 ▸ 界面* 中选择。

## 安装和更新 yt-dlp

*首选项 ▸ 网络 ▸ YouTube* 中有一个 **使用受管理的 yt-dlp** 复选框，用于控制
Vivace 如何获取并维护它用来播放 YouTube 链接的 `yt-dlp` 程序：

- **开启**（默认）— Vivace 可以为您安装 `yt-dlp` 并保持其为最新版本。
  **yt-dlp 路径：** 字段固定指向 Vivace 自身管理的副本，无法直接编辑；
  当您想要获取最新的官方版本时，请使用复选框旁边的 **安装／更新
  yt-dlp…** 按钮。**自动更新 yt-dlp：** 设置也会随之可用，让 Vivace
  自行运行此更新 —— **从不**、**每次运行 yt-dlp 时**、**每天一次** 或
  **每周一次**。自动更新会在真正解析或下载某个 YouTube URL 之前运行，
  因此在更新到期后的第一次播放会稍微多花一点时间；如果更新本身失败
  （例如没有网络连接），Vivace 会安静地继续使用已安装的版本，而不会
  阻塞播放。
- **关闭** —— 适用于您自行管理的 yt-dlp（例如通过 `pip` 或您操作系统的
  包管理器安装）。**yt-dlp 路径：** 字段将变为可编辑，方便您指向该副本，
  **自动更新 yt-dlp** 会被禁用 —— Vivace 永远不会安装或更新它不管理的
  yt-dlp。此模式下 **安装／更新 yt-dlp…** 按钮同样会被禁用。

## 导出 YouTube 下载所需的 Cookie

**Cookie 文件：** 字段（*首选项 ▸ 网络 ▸ YouTube*）可让 **下载并播放** 和
**外部工具** 这两种 YouTube 模式表现得如同您已登录 —— 这对于年龄限制、仅限
会员或其他需要账号验证的视频是必需的，也是解锁完整 HD/4K 下载的关键。它需
要一个采用经典 Netscape cookie 格式的纯文本 `cookies.txt` 文件（与 yt-dlp
自身的 `--cookies` 选项读取的格式相同）；Vivace 不会直接从浏览器的配置文件
中读取 Cookie。

**创建方法：**

1. 使用您想要使用其访问权限的账号，在您日常使用的浏览器中登录
   youtube.com。
2. 安装一个可导出 Netscape 格式的 Cookie 导出浏览器扩展 —— 对于
   Chrome、Edge 或 Brave，在浏览器的扩展商店中搜索类似
   “Get cookies.txt” 的扩展；对于 Firefox，搜索 “cookies.txt”。任何明确
   说明导出经典 Netscape `cookies.txt` 格式的扩展都可以使用。
3. 在打开 youtube.com 页面的标签页中，使用该扩展导出该网站的 Cookie，并
   将结果保存为磁盘上某处的 `.txt` 文件。
4. 在 Vivace 中，打开 *首选项 ▸ 网络 ▸ YouTube*，使用 **Cookie 文件：**
   旁边的 **浏览…** 按钮选择该文件。

**请注意：**

- `cookies.txt` 文件实际上等同于一个已保存的登录会话 —— 任何拥有该文件的
  人都可以冒充您的 YouTube 账号进行操作，直到 Cookie 过期或您退出登录为
  止。请将其存放在隐私安全的地方，不要与他人分享。
- Cookie 仅用于 **下载** 路径（下载并播放 / 外部工具）。Vivace 在
  **流式播放** 模式下有意从不发送 Cookie —— 已登录的流媒体 URL 会以
  Vivace 简单的视频播放器无法打开的方式绑定到该会话，因此即使配置了
  Cookie 文件，流式播放仍将保持匿名。
- Cookie 会过期。如果之前可以正常下载的内容开始失败，或回退到较低画质/
  公开版本的结果，请重新导出一个新的 `cookies.txt`。

## 安装 YouTube 下载所需的 Deno

不仅是 Vivace，yt-dlp 本身也会使用一个独立的外部 JavaScript 运行时，来
解决 YouTube 在发放视频真实下载 URL 之前设置的挑战。根据 yt-dlp 自己的
文档，不使用运行时运行已被视为“不推荐”，但并不会直接失败：可用的格式
会相应减少，并且 **对于已登录（Cookie）请求而言减少得尤为严重** ——
这正是 **下载并播放** 模式为解锁 HD、仅限会员和年龄限制视频而发出的
那种请求。**流式播放** 模式从不发送 Cookie（见上文“导出 YouTube 下载
所需的 Cookie”），因此不属于严重情况，在大多数情况下即使没有 Deno 也能
正常工作。这就是为什么 **Deno 路径：** 字段位于 *首选项 ▸ 网络 ▸
YouTube ▸ 下载并播放* 下，而不是作为一个通用的 YouTube 设置。yt-dlp
支持多种 JS 运行时；Deno 是它默认查找的那一个。

**安装方法：**

1. 根据您的操作系统，按照
   [docs.deno.com](https://docs.deno.com/runtime/getting_started/installation/)
   上的官方安装说明进行操作（根据平台不同，可以是安装脚本，或
   winget/scoop/Homebrew/apt 等包管理器）。
2. 确保 `deno` 可执行文件已加入系统 PATH —— 上述安装程序通常会自动
   完成此操作。在 Windows 上，请务必获取 `deno`，而不是 `denort`
   （另一个相关但在此处无法使用的可执行文件）。
3. 如果您不想修改 PATH，可以保持原样，转而将其完整路径粘贴到
   **Deno 路径：**（*首选项 ▸ 网络 ▸ YouTube ▸ 下载并播放*）中。
4. 安装完成后重启 Vivace（或者只需重试一次下载）。

**请注意：**

- 这是 **yt-dlp** 的依赖项，而不是 Vivace 本身的依赖项 —— Vivace 只会
  将 yt-dlp 作为外部进程运行，从不会自行调用 Deno。
- yt-dlp 需要相当新的 Deno 版本（截至撰写本文时为 2.3.0 或更高版本）。
  如果安装后下载仍然显示画质/格式降低的错误，请检查 `deno --version`
  并在版本过旧时进行更新。
- 这一要求源自 YouTube／yt-dlp 一方的变化，而非 Vivace —— 正是因为
  这个原因才存在 **Deno 路径：** 字段，只要 Deno 本身已安装并可访问，
  就无需进一步配置。
