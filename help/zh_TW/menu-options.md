# 選項

**選項** 選單包含偏好設定與介面設定。

- **偏好設定…**（`Ctrl+P`）— 主設定對話方塊：一般、介面、字幕、鍵盤與滑鼠、播放清單、
  光碟機、電視、檔案類型、更新、網路與進階。變更會立即套用；**取消** 會還原它們。
  - **一般 ▸ 視訊** 用於設定新開啟檔案的預設 **去交錯** 模式（無 / Yadif /
    Bwdif）—— 可在 *視訊 ▸ 去交錯* 中依檔案個別變更。
  - **網路** 包含 OpenSubtitles、YouTube、代理和投影四個分頁；**代理** 用於
    設定可選的 HTTP 或 SOCKS5 代理，套用於整個應用程式（OpenSubtitles 搜尋、
    更新檢查，以及僅限 HTTP 時的媒體播放和 yt-dlp）；**投影** 用於固定
    *播放 ▸ 投影至 ▸ 智慧型手機／平板電腦* 所監聽的連接埠。OpenSubtitles
    帳戶密碼和代理密碼現在都安全地儲存在您作業系統的認證管理員中，
    而非儲存在 Vivace 自身的設定裡。
- **在系統匣中顯示圖示** — 讓 Vivace 可從系統匣存取。
- **工具列**
  - **工具列** / **控制列** — 顯示或隱藏每個列。
  - **編輯主工具列…** / **編輯控制列…** — 選擇顯示哪些按鈕及其順序與圖示大小。
- **狀態列**
  - **顯示狀態列** 及其顯示內容：**視訊資訊**、**音訊資訊**、**格式資訊**、
    **位元率資訊**、**畫格計數器**、**顯示總時長**、**顯示剩餘時間** 與
    **顯示含毫秒的目前時間**。

**提示：** 整體版面（Basic / Mini / MPC）在 *偏好設定 ▸ 介面* 中選擇。

## 安裝和更新 yt-dlp

*偏好設定 ▸ 網路 ▸ YouTube* 中有一個 **使用受管理的 yt-dlp** 核取方塊，
用於控制 Vivace 如何取得並維護它用來播放 YouTube 連結的 `yt-dlp` 程式：

- **開啟**（預設）— Vivace 可以為您安裝 `yt-dlp` 並使其保持在最新版本。
  **yt-dlp 路徑：** 欄位固定指向 Vivace 自身管理的副本，無法直接編輯；
  當您想要取得最新的官方版本時，請使用核取方塊旁邊的 **安裝／更新
  yt-dlp…** 按鈕。**自動更新 yt-dlp：** 設定也會隨之變為可用，讓
  Vivace 自行執行此更新 —— **從不**、**每次執行 yt-dlp 時**、
  **每天一次** 或 **每週一次**。自動更新會在實際解析或下載某個
  YouTube URL 之前執行，因此在更新到期後的第一次播放會稍微多花一點
  時間；如果更新本身失敗（例如沒有網路連線），Vivace 會靜靜地繼續
  使用已安裝的版本，而不會阻擋播放。
- **關閉** —— 適用於您自行管理的 yt-dlp（例如透過 `pip` 或您作業系統
  的套件管理員安裝）。**yt-dlp 路徑：** 欄位會變為可編輯，方便您指向
  該副本，**自動更新 yt-dlp** 則會被停用 —— Vivace 永遠不會安裝或
  更新它不管理的 yt-dlp。此模式下 **安裝／更新 yt-dlp…** 按鈕同樣會
  被停用。

## 匯出 YouTube 下載所需的 Cookie

**Cookie 檔案：** 欄位（*偏好設定 ▸ 網路 ▸ YouTube*）可讓 **下載並播放** 與
**外部工具** 這兩種 YouTube 模式表現得如同您已經登入 —— 這對於有年齡限
制、僅限會員或其他需要帳號驗證的影片是必要的，也是解鎖完整 HD/4K 下載的
關鍵。它需要一個採用傳統 Netscape cookie 格式的純文字 `cookies.txt` 檔案
（與 yt-dlp 自身的 `--cookies` 選項所讀取的格式相同）；Vivace 不會直接從
瀏覽器的設定檔中讀取 Cookie。

**建立方式：**

1. 在您平常使用的瀏覽器中登入 youtube.com，並使用您想要使用其存取權的
   帳號。
2. 安裝一個可匯出 Netscape 格式的 Cookie 匯出瀏覽器擴充功能 —— 若是
   Chrome、Edge 或 Brave，請在瀏覽器的擴充功能商店中搜尋類似
   「Get cookies.txt」的項目；若是 Firefox，請搜尋「cookies.txt」。任何
   明確標示會以傳統 Netscape `cookies.txt` 格式匯出的擴充功能皆可使用。
3. 在開啟 youtube.com 分頁的情況下，使用該擴充功能匯出該網站的 Cookie，
   並將結果儲存為磁碟上某處的 `.txt` 檔案。
4. 在 Vivace 中開啟 *偏好設定 ▸ 網路 ▸ YouTube*，並使用 **Cookie 檔案：**
   旁邊的 **瀏覽…** 按鈕選取該檔案。

**請注意：**

- `cookies.txt` 檔案實際上等同於一個已儲存的登入工作階段 —— 任何持有此
  檔案的人都能以您的 YouTube 帳號身分操作，直到 Cookie 過期或您登出為
  止。請將它存放在隱密的地方，切勿與他人分享。
- Cookie 僅用於 **下載** 路徑（下載並播放／外部工具）。Vivace 在
  **串流播放** 模式下刻意絕不傳送 Cookie —— 已登入的串流網址會以 Vivace
  這款單純的影片播放器無法開啟的方式與該工作階段綁定，因此即使設定了
  Cookie 檔案，串流播放仍會維持匿名。
- Cookie 有效期有限。若先前能正常下載的內容開始失敗，或退回為畫質較低／
  公開版本的結果，請重新匯出新的 `cookies.txt`。

## 安裝 YouTube 下載所需的 ffmpeg

**下載並播放** 模式需要 `ffmpeg` 才能將 yt-dlp 下載的個別影片串流與音訊
串流合併成一個可播放的檔案 —— YouTube 很少以單一合併串流提供 HD，因此
影片軌與音訊軌會分別下載，然後再合併。**ffmpeg 位置：** 欄位（*偏好設定
▸ 網路 ▸ YouTube ▸ 下載並播放*）會告訴 yt-dlp 去哪裡找到它；留空則改用
系統 PATH 中的 `ffmpeg`。

**安裝方式：**

1. **Windows** —— 最簡單的方法是使用套件管理員：`winget install ffmpeg`
   （或 `scoop install ffmpeg` / `choco install ffmpeg`）。或者，從
   [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 或
   [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) 下載預先
   建置好的壓縮檔，並解壓縮到任意位置。
2. **macOS** —— `brew install ffmpeg`（Homebrew）。
3. **Linux** —— 透過您所用發行版的套件管理員安裝，例如
   `sudo apt install ffmpeg`（Debian/Ubuntu）、`sudo dnf install ffmpeg`
   （Fedora），或 `sudo pacman -S ffmpeg`（Arch）。
4. 若您已將 ffmpeg 加入系統 PATH，請將 **ffmpeg 位置：** 留空。否則，
   請將包含 `ffmpeg` 執行檔的 *資料夾* 路徑（而非執行檔本身）貼到該
   欄位中。
5. 安裝完成後重新啟動 Vivace（或者只需重試一次下載即可）。

**請注意：**

- 這和下方的 Deno 一樣，都是 **yt-dlp** 的相依性 —— Vivace 只會將其
  當作外部行程執行。
- **串流播放** 模式從不需要 ffmpeg，因為它播放的是單一的已合併串流；只有
  **下載並播放** 需要，因為該模式會分別取得影片與音訊，並在本機進行
  合併。
- 若下載因合併相關錯誤而失敗，請先檢查 ffmpeg 的位置 —— 除了 Deno
  缺失或過舊之外，這是最常見的原因。

## 安裝 YouTube 下載所需的 Deno

不僅是 Vivace，yt-dlp 本身也會使用一個獨立的外部 JavaScript 執行環境，
來解決 YouTube 在發放影片真實下載 URL 之前設下的挑戰。根據 yt-dlp
自身的文件，不使用執行環境運行已被視為「不建議」，但並不會直接失敗：
可用的格式會相應減少，而且 **對於已登入（Cookie）的請求而言減少得
尤其嚴重** —— 這正是 **下載並播放** 模式為解鎖 HD、僅限會員與有
年齡限制的影片而發出的那種請求。**串流播放** 模式從不傳送 Cookie
（見上文「匯出 YouTube 下載所需的 Cookie」），因此不屬於嚴重情況，
在大多數情況下即使沒有 Deno 也能正常運作。這就是為什麼 **Deno
路徑：** 欄位位於 *偏好設定 ▸ 網路 ▸ YouTube ▸ 下載並播放* 之下，
而不是作為一般的 YouTube 設定。yt-dlp 支援多種 JS 執行環境；Deno
是它預設尋找的那一個。

**安裝方式：**

1. 依您的作業系統，遵循
   [docs.deno.com](https://docs.deno.com/runtime/getting_started/installation/)
   上的官方安裝說明操作（依平台不同，可能是安裝指令碼，或
   winget/scoop/Homebrew/apt 等套件管理員）。
2. 請確保 `deno` 執行檔已加入系統 PATH —— 上述安裝程式通常會自動
   完成此操作。在 Windows 上，請務必取得 `deno`，而非 `denort`
   （另一個相關但在此處無法使用的執行檔）。
3. 如果您不想修改 PATH，可以保持原樣，改為將其完整路徑貼到
   **Deno 路徑：**（*偏好設定 ▸ 網路 ▸ YouTube ▸ 下載並播放*）中。
4. 安裝完成後重新啟動 Vivace（或者只需重試一次下載即可）。

**請注意：**

- 這是 **yt-dlp** 的相依性，而非 Vivace 本身的相依性 —— Vivace 只會
  將 yt-dlp 當作外部行程執行，從不會自行呼叫 Deno。
- yt-dlp 需要相當新的 Deno 版本（截至撰寫本文時為 2.3.0 或更新版本）。
  若安裝後下載仍顯示畫質／格式降低的錯誤，請檢查 `deno --version`
  並在版本過舊時進行更新。
- 這項要求源自 YouTube／yt-dlp 那一方的變化，而非 Vivace —— 正是
  因為這個原因才存在 **Deno 路徑：** 欄位，只要 Deno 本身已安裝且
  可存取，就不需要進一步設定。

## 點陣圖字幕平滑處理

*偏好設定 ▸ 字幕 ▸ 點陣圖字幕* 中有一個 **平滑處理：** 設定（0–3，預設值為
1），用於以圖像而非文字形式呈現的字幕——DVD 子畫面、PGS 和 DVB 軌道。這既涵蓋
真正 DVD 光碟自帶的字幕，也涵蓋一般影片檔案中嵌入的同類字幕軌道（例如帶有
`dvd_subtitle` 編解碼器軌道的 .mp4 檔案）。這些格式是在製作來源內容時以原生
標準畫質（SD）解析度預先算繪並燒錄的點陣圖影像——放大到現代視窗尺寸後，其邊緣
可能會有明顯鋸齒。Vivace 可以套用輕微模糊來柔化這些邊緣：

- **0** —— 關閉；按原樣顯示原始字幕點陣圖。
- **1**（預設值）—— 柔化最粗糙的邊緣，同時讓文字大致保持原有亮度。
- **2** / **3** —— 模糊程度逐級加強。

此設定僅影響點陣圖字幕 —— 對 Vivace 自身的外部字幕算繪器（SRT/VTT/ASS）或
一般文字字幕軌道均無影響，兩者使用完全不同的算繪路徑。
