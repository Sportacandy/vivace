# オプション

**オプション** メニューからは、設定やアプリの各種調整にアクセスします。

- **設定…**（`Ctrl+P`）— メインの設定ダイアログを開きます。左側の一覧から
  各セクション（一般、インターフェース、プレイリスト、字幕、ネットワーク、
  テレビとラジオ、キーボードとマウス、更新、ファイルの種類、詳細）へ移動します。
  変更は即座に反映され、**キャンセル** で元に戻ります。
  - **一般 ▸ 映像** では、新しく開くファイルの既定の **インターレース解除**
    モード（なし／Yadif／Bwdif）を設定します。ファイルごとに変更するには
    *映像 ▸ インターレース解除* を使用してください。
  - **一般 ▸ 優先する音声と字幕** では、ファイルの埋め込みトラックから Vivace
    が自動選択する言語を設定します。**既定で字幕を表示** をオンにすると、
    利用可能な場合に自動的に字幕がオンになります。そのサブオプション
    **…ただし、音声がすでに優先言語の場合を除く** をオンにすると、実際に
    選択された音声トラックと言語が一致する場合は、その自動字幕の表示を
    省略します — 音声の内容をすでに理解できていて、同じ言語の字幕が気を
    散らすだけの場合に便利です。
  - **ネットワーク** には OpenSubtitles・YouTube・プロキシ・キャストの各タブが
    あります。**プロキシ** タブでは、任意の HTTP または SOCKS5 プロキシをアプリ
    ケーション全体（OpenSubtitles 検索・アップデート確認、および HTTP の場合の
    みメディア再生と yt-dlp）に適用できます。**キャスト** タブでは、*再生 ▸
    キャスト ▸ スマートフォン/タブレット* が待ち受けるポートを固定します。
    OpenSubtitles アカウントのパスワードとプロキシのパスワードは、Vivace 自体の
    設定ファイルにではなく、お使いのオペレーティングシステムの資格情報マネー
    ジャーに安全に保存されます。
- **システムトレイにアイコンを表示** — トレイアイコンを切り替えます。閉じたときに
  トレイへ最小化できます。
- **ツールバー** — メインツールバーとコントロールバーの表示切り替えと、
  レイアウト編集（**メインツールバーを編集** / **コントロールバーを編集**）。
- **ステータスバー** — ステータスバーの表示切り替えと、表示する情報（映像・音声情報、
  形式、ビットレート、フレームカウンター、時間表示）の選択。

## キーボードとマウス

*設定 ▸ キーボードとマウス* で、ほとんどの操作のショートカットを変更できます。
ショートカットをクリックして新しいキーの組み合わせを押します。競合は検出され、
一覧の絞り込みや、個別・一括のリセットもできます。編集は即座に反映・保存されます
（設定の OK／キャンセルの対象外です）。

同じページで、マウスの左クリック・ダブルクリック・中クリック・ホイールの動作も
割り当てられます。

## yt-dlp のインストールと更新

*設定 ▸ ネットワーク ▸ YouTube* にある **管理された yt-dlp を使う** チェック
ボックスで、Vivace が YouTube 再生に使う `yt-dlp` プログラムの入手・維持方法を
切り替えられます。

- **オン**（既定）— Vivace が `yt-dlp` をインストールし、最新の状態に保つこと
  ができます。**yt-dlp のパス:** フィールドは Vivace 自身の管理下にあるコピー
  に固定され、直接編集できません。最新の公式リリースを取得したいときは、
  チェックボックスの横にある **yt-dlp をインストール／更新…** ボタンを使い
  ます。**yt-dlp を自動的に更新:** の設定も選べるようになり、Vivace 自身に
  更新を任せられます — **しない**、**yt-dlp を実行するたび**、**1日に1回**、
  **1週間に1回** のいずれかです。自動更新は、YouTube の URL が実際に解決・
  ダウンロードされる直前に実行されるため、更新が必要になった直後の最初の
  再生は少し時間がかかります。更新自体が失敗した場合（ネットワークがない
  場合など）は、再生を止めることなく、既にインストールされているバージョン
  のまま静かに処理を続行します。
- **オフ** — `pip` や OS のパッケージマネージャーなどで自分自身が管理している
  yt-dlp を使う場合の設定です。**yt-dlp のパス:** フィールドが編集可能になり、
  そのコピーを指定できます。**yt-dlp を自動的に更新** は無効になり、Vivace が
  管理していない yt-dlp をインストールしたり更新したりすることはありません。
  このモードでは **yt-dlp をインストール／更新…** ボタンも無効になります。

## YouTubeダウンロード用のCookieのエクスポート

**Cookie ファイル:** フィールド（*設定 ▸ ネットワーク ▸ YouTube*）を使うと、
**ダウンロードして再生** および **外部ツール** の YouTube モードで、サインイン
した状態であるかのように動作させることができます。年齢制限付き・メンバー限定
などアカウント認証が必要な動画に必要で、フル HD/4K のダウンロードを可能にする
ものでもあります。このフィールドには、従来からある Netscape 形式の平文
`cookies.txt` ファイル（yt-dlp 自体の `--cookies` オプションが読み込むのと同じ
形式）を指定します。Vivace はブラウザのプロファイルから直接 Cookie を読み取る
ことはありません。

**作成手順:**

1. 普段使っているブラウザで youtube.com にサインインします。使用したいアクセ
   ス権を持つアカウントでログインしてください。
2. Netscape 形式で書き出せる Cookie エクスポート用のブラウザ拡張機能をインス
   トールします。Chrome、Edge、Brave では、ブラウザの拡張機能ストアで
   「Get cookies.txt」のようなものを検索してください。Firefox では
   「cookies.txt」を検索してください。従来の Netscape `cookies.txt` 形式で
   書き出すと明記されている拡張機能であれば、どれでも使用できます。
3. youtube.com のタブを開いた状態で、その拡張機能を使ってそのサイトの
   Cookie をエクスポートし、結果をディスク上のどこかに `.txt` ファイルとして
   保存します。
4. Vivace で *設定 ▸ ネットワーク ▸ YouTube* を開き、**Cookie ファイル:** の
   横にある **参照…** を使ってそのファイルを選択します。

**注意事項:**

- `cookies.txt` ファイルは、事実上保存されたログインセッションです。この
  ファイルを持っている人は誰でも、Cookie が失効するかサインアウトするまで、
  あなたの YouTube アカウントとして操作できてしまいます。人目につかない場所
  に保管し、他人と共有しないでください。
- Cookie が使われるのは **ダウンロード** 系の経路（ダウンロードして再生／
  外部ツール）のみです。Vivace は **ストリーミング** モードでは意図的に
  Cookie を送信しません — サインイン済みのストリーム URL はそのセッションに
  紐付けられており、Vivace の単純な動画プレーヤーでは開けない形式になって
  しまうためです。そのため、Cookie ファイルが設定されていても、ストリーミ
  ングは匿名のまま行われます。
- Cookie には有効期限があります。以前は機能していたダウンロードが失敗したり、
  画質が低い/非会員向けの結果にフォールバックし始めた場合は、新しい
  `cookies.txt` を書き出し直してください。

## YouTubeダウンロード用のffmpegのインストール

**ダウンロードして再生** モードでは、yt-dlp がダウンロードした別々の映像
ストリームと音声ストリームを1つの再生可能なファイルに結合するために
`ffmpeg` が必要です — YouTube では HD が単一の結合済みストリームとして
提供されることはほとんどなく、映像トラックと音声トラックが別々にダウン
ロードされてから結合されます。**ffmpeg の場所:** フィールド（*設定 ▸
ネットワーク ▸ YouTube ▸ ダウンロードして再生*）は、yt-dlp にその場所を
伝えます。空欄のままにすると、代わりにシステムの PATH にある `ffmpeg` が
使われます。

**ffmpeg のインストール方法:**

1. **Windows** — 最も簡単なのはパッケージマネージャーを使う方法です:
   `winget install ffmpeg`（または `scoop install ffmpeg` /
   `choco install ffmpeg`）。あるいは、[gyan.dev](https://www.gyan.dev/ffmpeg/builds/)
   や [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) から
   ビルド済みアーカイブをダウンロードして、どこかに展開してください。
2. **macOS** — `brew install ffmpeg`（Homebrew）。
3. **Linux** — お使いのディストリビューションのパッケージマネージャーで
   インストールします。例: `sudo apt install ffmpeg`（Debian/Ubuntu）、
   `sudo dnf install ffmpeg`（Fedora）、`sudo pacman -S ffmpeg`（Arch）。
4. ffmpeg をシステムの PATH に追加した場合は、**ffmpeg の場所:** を空欄の
   ままにしてください。そうでない場合は、`ffmpeg` の実行ファイルそのもの
   ではなく、それが入っている *フォルダー* のパスをそのフィールドに
   貼り付けてください。
5. インストール後は Vivace を再起動してください（またはダウンロードを
   やり直すだけでも構いません）。

**注意事項:**

- これは下記の Deno と同様、**yt-dlp** の依存関係です — Vivace は常にこれを
  外部プロセスとして実行するだけです。
- **ストリーミング** モードは、すでに結合済みの単一ストリームを再生する
  ため、ffmpeg を必要としません。必要になるのは **ダウンロードして再生**
  モードだけです。このモードは映像と音声を別々に取得し、ローカルで結合
  するためです。
- ダウンロードが結合関連のエラーで失敗する場合は、まず ffmpeg の場所を
  確認してください — Deno が未インストールまたは古い場合を除けば、最も
  よくある原因です。

## YouTubeダウンロード用のDenoのインストール

Vivace だけでなく yt-dlp 自体も、YouTube が動画の実際のダウンロード URL を
渡す前に出す課題を解くために、別途外部の JavaScript ランタイムを使用します。
yt-dlp 自身のドキュメントによれば、これを使わずに実行することは「非推奨」
ではあるものの、完全に失敗するわけではありません — 利用できる形式が単に
減るだけですが、**サインイン済み（Cookie）のリクエストでは深刻に**減ります。
これはまさに **ダウンロードして再生** モードが HD・メンバー限定・年齢制限
付きの動画を解放するために行うリクエストの種類です。**ストリーミング**
モードは Cookie を送信しないため（上記の「YouTubeダウンロード用のCookieの
エクスポート」を参照)、深刻なケースには当たらず、たいていの場合 Deno なしでも
問題なく動作します。これが **Deno のパス:** フィールドが一般的な YouTube
設定ではなく *設定 ▸ ネットワーク ▸ YouTube ▸ ダウンロードして再生* に
あることの理由です。yt-dlp は複数の JS ランタイムに対応していますが、
既定で探すのが Deno です。

**Deno のインストール手順:**

1. お使いの OS 向けに、[docs.deno.com](https://docs.deno.com/runtime/getting_started/installation/)
   の公式インストール手順に従ってください（インストーラースクリプト、または
   プラットフォームに応じて winget/scoop/Homebrew/apt などのパッケージ
   マネージャーを使用します）。
2. `deno` 実行ファイルがシステムの PATH に含まれるようにしてください —
   上記のインストーラーは通常これを自動で行います。Windows では、
   `denort`（別の関連実行ファイルで、ここでは使えません）ではなく `deno`
   を取得するようにしてください。
3. PATH を変更したくない場合は、そのままにしておき、代わりにそのフル
   パスを **Deno のパス:**（*設定 ▸ ネットワーク ▸ YouTube ▸ ダウンロード
   して再生*）に貼り付けてください。
4. インストール後は Vivace を再起動してください（またはダウンロードを
   やり直すだけでも構いません）。

**注意事項:**

- これは **yt-dlp** の依存関係であり、Vivace 自体の依存関係ではありません
  — Vivace は yt-dlp を外部プロセスとして実行するだけで、Deno を直接
  呼び出すことはありません。
- yt-dlp は比較的新しいバージョンの Deno を必要とします（本稿執筆時点で
  2.3.0 以降）。インストール後も画質・形式のエラーが解消しない場合は、
  `deno --version` を確認し、古ければ更新してください。
- この要件は Vivace ではなく YouTube／yt-dlp 側の変更に由来します —
  **Deno のパス:** フィールドが存在するのはまさにこのためであり、
  Deno 自体をインストールして到達可能にすれば、それ以上の設定は
  必要ありません。

## ビットマップ字幕のスムージング

*設定 ▸ 字幕 ▸ ビットマップ字幕* には、テキストではなく画像として描画される
字幕（DVD サブピクチャー、PGS、DVB トラック）向けの **スムージング:** 設定
（0～3、既定値は 1）があります。これは実際の DVD ディスク自体の字幕だけで
なく、通常の動画ファイルに埋め込まれた同種の字幕トラック（例えば
`dvd_subtitle` コーデックのトラックを持つ .mp4 ファイルなど）にも当てはまり
ます。これらの形式は、素材の制作時に標準解像度（SD）で焼き込まれたビット
マップ画像であり、現代のウィンドウサイズに拡大すると輪郭がギザギザに見える
ことがあります。Vivace はこの輪郭を軽いぼかしで滑らかにできます。

- **0** — オフ。元の字幕ビットマップを制作時のまま表示します。
- **1**（既定値）— 明るさをほぼそのまま保ちながら、最も目立つ輪郭の
  ギザギザを和らげます。
- **2** / **3** — 段階的に強いぼかしをかけます。

この設定はビットマップ形式の字幕のみに影響し、Vivace 自身の外部字幕
レンダラー（SRT/VTT/ASS）や、通常のテキスト形式の字幕トラックには影響
しません。これらは別の描画経路によるものです。
