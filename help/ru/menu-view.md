# Вид

Меню **Вид** показывает сведения и дополнительные панели.

- **Сведения и свойства…** — подробное окно о текущем медиа: общие сведения,
  демультиплексор и видео-/аудиокодеки (с выделением форматов, поддерживаемых
  движком Vivace). Только для информации.
- **Плейлист** (`F9`) — показать или скрыть плейлист. В зависимости от
  *Настройки ▸ Интерфейс* он отображается как закреплённая панель или отдельное
  окно. См. [Открыть](menu-open.md) для загрузки плейлистов.
  - Каждая строка показывает миниатюру — соседний файл изображения рядом с
    медиафайлом (уже лежащий рядом файл «<name>.jpg»), если он существует,
    иначе кадр, автоматически захватываемый в фоновом режиме. Кнопка в
    правом верхнем углу плейлиста переключает размер строки/миниатюры
    (**Маленький**/**Средний**/**Большой**); при значениях «Маленький» и
    «Средний» выбранная строка и строка воспроизводимого элемента
    увеличиваются, показывая более крупное превью. *Настройки ▸ Плейлист ▸
    Прочее* содержит независимую настройку для каждой из них
    («Миниатюра выбранного элемента» / «Миниатюра воспроизводимого
    элемента»): без увеличения, увеличение только этой строки, либо также
    плавное уменьшение размера для пары соседних строк до того же размера
    (значение по умолчанию для обеих). Сгенерированные миниатюры кешируются
    (при заполнении кеша удаляется та, что дольше всего не показывалась);
    размер кеша настраивается в *Настройки ▸ Плейлист ▸ Прочее ▸
    Максимальное число кешированных миниатюр*.
- **Экранное меню (OSD)** — отображение поверх видео:
  - уровень детализации (только субтитры; громкость + перемотка; громкость +
    перемотка + таймер) расширяется; длительность OSD и размер шрифта — в
    *Настройки ▸ Интерфейс ▸ Текст*.
  - Сообщения об ошибках (неудачная загрузка, папка без DVD-видео,
    нечитаемый файл ярлыка и т. п.) всегда отображаются ровно 20 секунд,
    независимо от настроенной длительности OSD — этого достаточно, чтобы
    прочитать даже длинное сообщение об ошибке.
